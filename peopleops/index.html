Perlu internet atau server?

Untuk KPI Engine dan RapiHR, internet hanya dipakai saat aktivasi lisensi. Setelah itu aplikasi berjalan offline dan data tersimpan di laptopmu sendiri.

Bisa dipakai di HP?

KPI Engine dan RapiHR dipakai di laptop atau PC dengan Chrome atau Edge. Tools custom bisa dibuat untuk dibuka dari HP.

Kalau ganti laptop, lisensinya bagaimana?

Buat backup di laptop lama, pulihkan di laptop baru, lalu tekan Transfer lisensi. Data dan logo ikut pindah. Jatah transfer mandiri 2 kali setahun.

Saya tidak paham teknologi, bisa pakai?

Bisa. Tampilannya dibuat sesederhana mungkin dan ada panduan singkat. Kalau bisa pakai WhatsApp, kamu bisa pakai tools ini.

Data usaha saya aman?

Untuk aplikasi offline, data tidak pernah meninggalkan laptopmu. Untuk tool online, data disimpan terpisah per usaha, dilindungi login, dan dibackup rutin. Data tetap milikmu dan bisa diekspor kapan saja.

Kalau nanti butuh fitur tambahan?

Tools bisa dikembangkan bertahap. Mulai dari satu modul, lalu tambah modul lain saat usahamu berkembang.

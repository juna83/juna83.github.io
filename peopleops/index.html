    Pertanyaan yang sering muncul.

    KPI Engine perlu internet atau server?

    Tidak. Internet hanya dipakai sekali untuk aktivasi lisensi. Setelah itu aplikasi berjalan offline dan data tersimpan di folder laptopmu sendiri.

    Kalau ganti laptop, lisensinya bagaimana?

    Buat backup di laptop lama, pulihkan di laptop baru, lalu tekan Transfer lisensi. Semua data, logo, dan evidence ikut pindah. Jatah transfer mandiri 2 kali setahun.

    Saya tidak paham teknologi, bisa pakai?

    Bisa. Tampilannya dibuat sesederhana mungkin dan ada pelatihan singkat. Kalau kamu bisa pakai WhatsApp, kamu bisa pakai tool ini.

    Berapa lama pembuatannya?

    Tool siap pakai aktif 1–2 hari. Tool custom 1–3 minggu, HRIS 4–6 minggu. Job description 3–5 hari kerja dan SOP 5–7 hari kerja. Estimasi pastinya saya kirim bersama penawaran.

    Data usaha saya aman?

    Untuk tool online, data tersimpan di server terpisah per usaha, dilindungi login, dan dibackup rutin. Untuk KPI Engine, data tidak pernah meninggalkan laptopmu. Keduanya tetap milikmu dan bisa diekspor kapan saja.

    Bisa dipakai di HP?

    Bisa. Semua tools dibuka lewat browser dan tampilannya menyesuaikan layar HP, tablet, maupun laptop.

    Kalau nanti butuh fitur tambahan?

    Tool bisa dikembangkan bertahap. Mulai dari satu modul, lalu tambah modul lain saat usahamu berkembang.
